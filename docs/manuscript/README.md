# 《AI 原生软件工程》书稿总览

> 一本关于**大组织如何在 AI 失灵时接管**的书。
> 写作对象：300 人、12 业务域、5 端、200+ 仓库、300+ 微服务的平台。

本目录是按《写作宪法》产出的**地基 + 全部 29 章正文 + 配套附录**。所有数字、事故、角色立场相互自洽，以 [`02-数字清单.md`](./02-数字清单.md) 为唯一事实来源。
