## 本书约定

- **第一人称仅出现在第八部分四个案例章**（四位不同叙述者）。理论章采用第三人称。
- **代码块**：Java / Go / Python / TypeScript / SQL / YAML 等真实技术栈写法。
- **表格**：`四案例映射` 展示同一原则在四个案例中的不同体现。
- **引用块**：关键原则、人物原话与警示。
- **配图**：Mermaid 即代码；案例章另有抽象头图。
- **证据边界**：四案例均为自洽虚构脱敏示范，数字以数字清单为准。
